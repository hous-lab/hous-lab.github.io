Hous Lab 是我的个人技术知识库的公开层，方向是：

> **Autonomous Driving × AI Systems × Edge Intelligence**

## 这里记录什么

- **部署实践** — 推理引擎、车端平台上的真实部署经验
- **模型量化** — 量化策略与精度取舍
- **性能分析** — Profiling 与瓶颈定位方法论
- **研究与笔记** — 研究工作与技术基础笔记

## 写作原则

1. **只写真实做过的事。** 每个结论都有实验数据或 profiling 结果支撑。
2. **保留失败的路线。** "为什么不行"往往比"最终用了什么"更有价值。
3. **文章模板统一。** TL;DR → Problem → Approach → What Didn't Work → Lessons Learned。

## 发布流程

所有文章**经作者确认后才会发布**。仓库内未合并到 `main` 的草稿不会上线。

## 隐私说明

本站统计页面展示的是**国家级匿名聚合**数据：不存储原始 IP 与 User-Agent（仅用日盐哈希做 24 小时去重），不使用任何跟踪 Cookie。唯一写入浏览器的 Cookie 是点赞状态位，仅记录你是否点过赞，无跟踪用途。评论数据存放于 GitHub Discussions。
